## الاختبارات المنفذة

- `bash lib/db/rebuild/run-local-test.sh`: نجح من إعادة بناء PostgreSQL مؤقتة، بما فيها 0021. شمل 60 تحقق HTTP للمخزون، واختبارًا محليًا للحركات والعزل، إضافة إلى اختبارات المالية والكتالوج والأسطول القائمة؛ لم يطبق `0009` ولم يكتب إلى Supabase.
- تحقق منفصل من صياغة مشغّل الترحيل ثم فحصه الحي بوضع القراءة فقط. نتيجة 0021: `absent`، ولا يوجد اختلاف في بصمة الملف.
- `pnpm run typecheck`: نجح. بناء API وبناء الويب نجحا؛ لا يوجد جزء ويب يتجاوز 500 kB. تحذير الحزمة الخادمية 3.3 MB منفصل عن تنزيل المتصفح.
- لا اختبار تخزين حي أو رفع/تنزيل ملف، ولا PDF أو بريد، ولا بيع خدمة أو شراء مورد أو تسوية.

## ما لا توفره هذه الحزمة

- لا تربط الحجز أو الصرف بأمر خدمة حقيقي أو بتحصيل مالي؛ هذه العقود ليست دورة تشغيل كاملة.

- لا تنشئ أصناف كتالوج؛ تستعمل أصناف الكتالوج القائمة عند توفرها.
- مستندات المخزون لا ترفع مرفقًا إلى تخزين خاص بعد؛ ولم يُختبر Supabase Storage.

## الفحوص المنفذة

- `pnpm --filter @workspace/api-spec run codegen` — ناجح.
- `pnpm --filter @workspace/pertomax-eg-web run typecheck` — ناجح.
- `pnpm --filter @workspace/api-server run typecheck` — ناجح.
- `PORT=5000 BASE_PATH=/ pnpm --filter @workspace/pertomax-eg-web run build` — ناجح.
- `bash lib/db/rebuild/run-local-test.sh` — ناجح في PostgreSQL محلي مؤقت. يتضمن 36 تحقق أسطول، 52 تحقق تكامل أسطول/مالية، 47 تحقق جهات/مستخدمين، و21 assertion لواجهات الكتالوج؛ ونجحت اختبارات ترحيل الكتالوج للملكية والنطاق والسعر والتوقيت والتعارض والإيقاف ومزايا الفئات والمنح.
- في المعاينة المستمرة، استجابت قراءات الفئات ودليل التجار والمرجع والسعر بحالة 200 في الجلسة المتاحة؛ ورفضت نقطة API بلا جلسة بحالة 401. لم تُختبر كتابة حية أو حفظ سعر/صنف.
- لا اختبار بحساب أو سجل أو صورة أو سعر حي، ولا إرسال بريد أو تشغيل مبيعات أو مخزون.

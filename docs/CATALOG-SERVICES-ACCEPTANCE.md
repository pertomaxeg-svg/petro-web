- `pnpm run typecheck` و`PORT=3000 BASE_PATH=/pertomax-eg-web pnpm --filter @workspace/pertomax-eg-web run build` و`pnpm --filter @workspace/api-server run build` — ناجحة. البناء لا يثبت جلسة لوحة مصادق عليها.

## المراجع والقيود التشغيلية

- استُخدمت مكونات React/Vite وLucide وتوكنات المشروع القائمة دون تغيير إطار أو تبعية واجهات.
- تعذر فتح مراجع Supabase الرسمية عبر خدمة البحث/الجلب المتاحة (402 Payment Required)؛ لم أزعم مراجعتها. طبّق الترحيل عبر المشغل المعتمد واختبارات PostgreSQL، مع المحافظة على ACL الافتراضية.
- تعذر تشغيل مراجعة معماري مستقلة في وضع Free؛ أُنجزت مراجعة يدوية للـRPC/RLS والـAPI والواجهة. لا ادعاء بمراجعة آلية.
- لم تُبنَ نقاط البيع والطلبات والمدفوعات والخصومات والضرائب وتسويات التجار أو دورة الخدمة الميدانية. مخزون 0021 لم يُطبق على Supabase؛ لا تعلن دورة المخزون الحية أو البيع كوظيفة فعالة.
- قائمة الأصناف المركزية تختار تاجرًا واحدًا في كل مرة وتُجزّئ القراءة؛ لا توجد بعد شاشة تجميع شاملة لكل الأصناف عبر جميع التجار.
- سعر الإضافة في الغسيل غير منفصل عن السعر الأساسي، والتدخل الإداري في كتالوج التاجر يتطلب عضوية/تفويض التاجر الحالي؛ لم تُنشأ صلاحية انتحال إداري.
- لم يُختبر رفع/تنزيل Supabase Storage الحي أو واجهة داخلية بجلسة مالك؛ المتبقي هو تحقق مصرح به من مالك الجلسة لمرفق اختباري معزول، دون إنشاء أصناف فعلية.

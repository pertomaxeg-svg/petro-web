5. **التحقق قبل القطع:** انتظر اكتمال تحديث جميع نسخ API، وتحقق من عدم بقاء مستهلك يستخدم RPC القديم، وراجع سجل أخطاء مسار الحالة. لا تنتقل إلى 0009 إذا بقي مستهلك غير معروف.

## خطة الرجوع

- **بعد 0009:** إذا أظهر التحقق أن مستهلكًا قديمًا ما زال يحتاج المسار السابق، أعد فقط منحه السابق `EXECUTE` إلى `authenticated` داخل معاملة، وتحقق أن `PUBLIC` و`anon` بقيا مرفوضين وأن `service_role` لم يتغير؛ ثم أعد API إلى النسخة المتوافقة المناسبة. لا تضعف TLS ولا تمسح بيانات أو أحداث تدقيق.

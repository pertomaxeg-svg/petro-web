# Pertomax EG — قبول إدارة الأسطول المركزية

## النطاق والحالة

هذه الحزمة للإدارة المركزية فقط. لا توجد حسابات دخول للسائقين، أو بيانات أعمال اختبارية في Supabase، أو تشغيل خدمة تاجر، أو لوحة شركة/عامل، أو كتابة فعلية على NFC. المعروف من المستهلكين داخل هذا المشروع هو واجهة الإدارة وAPI الأسطول؛ لم يُفترض أو يُفحص مستهلك خارجي.

طُبق 0016 وحده بعد اختبار معزول ومطابقة مباشرة على `msvgzsfzrqlrfpstthhe`. سجل الترحيل `20261016140606`، بصمة SQL `60c94d0f5916383a8f4dfbbf634fc7c7aa5426868519f0e21cb421fab04f7245`. بقي 0009 مؤجلًا، ولم تُعد 0014 أو 0015 أو أي baseline.

## نتائج التحقق

- PostgreSQL المؤقت: 36 تحققًا لـ0014 و52 تحققًا إضافيًا للأسطول/المالية تشمل التوقيت والحدود والنسخ والتغطية والنقل والتاريخ؛ لم تُستخدم بيانات أو محاكاة Supabase للدفتر.
- API محلي معزول: 36 تأكيدًا لمسارات الأسطول تشمل المصادقة والأدوار، قائمة الشركات والفروع، سعر NFC، ملف السائق وإسناده وتاريخه دون PIN، استعادة الحجوزات، نسخ المعدل وإعادة المحاولة. استخدم خادم HTTP محليًا ونقل Supabase وهميًا في هذا الاختبار فقط.
- المجموعة المحلية الأوسع اجتازت اختبارات المستخدمين والباقات والمالية والتزامن و0014/0015؛ 0009 لم يُشغّل.
- فحص الأنواع الكامل لمساحات العمل نجح. بناء الويب نجح؛ أكبر ملف JavaScript عام 347.46 kB غير مضغوط و94.64 kB مضغوطًا. جزء الأسطول 115.13/31.17 kB. تحذير حزمة API البالغ 3 MB مع خرائط مصدر 4.9 MB يخص الخادم، لا تنزيل المتصفح؛ لم يُرفع حد التحذير.
- preflight/postflight المباشران: 24 نطاق ACL و300 صف امتياز بلا تغيير؛ بصمة النطاق بقيت `65e09b76b80628c531e6e223128f0a201befefeb9eaa75685dae5dafdc337cea`. طابقت المفاتيح السبعة المتأثرة، وبقيت دالة حالة المستخدم القديمة و0008 بصلاحياتهما. كانت صفوف الأسطول المتأثرة صفرًا قبل التطبيق؛ لم ينشئ 0016 بيانات أعمال.
- لا تمثل هذه النتائج اختبار Auth أو Supabase Storage أو NFC على جهاز فعلي، ولا تفعيل خدمة أو تحصيلًا ماليًا حيًا.

## المتبقي قبل اعتماد التشغيل الميداني

- يراجع المالك الواجهات الداخلية بجلسة أدمن عادية دون حفظ بيانات اختبار؛ جلسة المتصفح المصرح بها غير متاحة في هذا التحقق.
- يفحص مستخدم مصرح به رفع وتنزيل مستند خاص على Supabase Storage الحي؛ الاختبار المحلي لا يثبت ذلك.
- تحتاج مسارات الخدمة والعامل إلى ربط فعلي بالأهلية والحجز/الاستهلاك والعداد؛ وتبقى الكتابة الفعلية على NFC واختبار الجهاز، PDF والبريد، خارج الحزمة.
- استهلاك الوقود الفعلي ينتظر أحداث تعبئة موثوقة، ولا ينشئ هذا العمل أسطولًا تجريبيًا أو دورة خدمة وهمية.

المبادئ المستخدمة: تصميم Pertomax وRTL الحاليان، ومبادئ تنظيم لوحة الإدارة والجداول والحالات الموصوفة في متطلبات المالك. استخدم وكيل التصميم ومراجع React/Vite وpnpm/OpenAPI المتاحة؛ لم تُستخدم مهارات غير مثبتة أو مراجع خارجية لم تُتح. لم يُستبدل التخزين الخاص القائم بنظام تخزين آخر.

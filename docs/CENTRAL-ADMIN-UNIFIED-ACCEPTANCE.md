# Pertomax EG — توحيد الإدارة المركزية

## النطاق والحالة

استكمال للوحة الجهات والمستخدمين والأسطول على التاريخ المنقح؛ الترحيلات المعتمدة السابقة، ومنها 0016 و0022، باقية كما هي. لم يُطبق ترحيل أو تُكتب بيانات أعمال جديدة على Supabase في إعادة التحقق هذه، ولا تغيير لتهيئة المالك؛ `0009` ما زال مؤجلًا.

## التحقق المنفذ

- `pnpm --filter @workspace/pertomax-eg-web run typecheck`: ناجح.
- `pnpm --filter @workspace/api-server run typecheck`: ناجح.
- `PORT=3000 BASE_PATH=/pertomax-eg-web pnpm --filter @workspace/pertomax-eg-web run build`: ناجح.
- `pnpm --filter @workspace/api-server run build`: ناجح؛ حزمة الخادم 3.3 MB وخرائطها 5.6 MB، وهي لا تُحمّل للمتصفح.
- `bash lib/db/rebuild/run-local-test.sh`: ناجح باستخدام PostgreSQL محلي مؤقت وبيانات اصطناعية؛ الاختبارات الحالية تشمل 36 تحققًا لأسطول 0014، و52 تحققًا لدمج الأسطول والمالية، و47 تحققًا لملفات الجهات/المستخدمين وقراءة الاشتراك والحسابات والسعر، إضافة إلى تكاملات المالية والترحيلات. لم يُشغّل `0009`.
- اختبار متصفح محلي متصل بـAPI وPostgreSQL مؤقت أثبت حفظ سعر وحق وإعداد الخطة بعد إعادة التحميل، وبقاء مسودة الوقود، والوصول بنموذج المركبة إلى المراجعة. لم يحفظ بيانات أسطول.
- نقاط اختبار API استخدمت خادم HTTP محليًا ونقل Supabase محاكى إلى قاعدة PostgreSQL المعزولة؛ اختبارات سياسة التغطية والحجز استخدمت قاعدة PostgreSQL الحقيقية المؤقتة. هذا ليس اختبارًا حيًا لخدمة Supabase.
- لم تُستخدم جلسة مالك حية أو تجاوز مصادقة أو إرسال بريد أو تخزين حي. الجلسة الاختبارية اصطناعية ومحصورة بالبيئة المحلية؛ لم تُنشأ بيانات أعمال أو حسابات أو معاملات اختبار في Supabase.

## المراجع والقيود

استُخدمت مكونات وتوكنات المشروع القائمة، وتعليمات React/Vite، ومراجعة تصميم متخصصة على الملفات الحالية. لم أتحقق من فتح مراجع خارجية إذا لم تُحمّل. لم يُطبّق ترحيل جديد في هذه الجولة، ولم تتغير ACL أو الأسرار أو الاتصالات.

## المتبقي المحدد

1. مراجعة مالك مصرح بها للصفحات بعد تسجيل الدخول على 1280 و1440 وهاتف 390؛ أداة المتصفح المتاحة لا تحمل جلسة المالك.
2. اختبار رفع/تنزيل Storage على Supabase لا يزال مفتوحًا؛ لم أستخدم اتصالًا إداريًا لتجاوزه ولم أرفع ملفًا أو أنشئ سجلًا حيًا.
3. لا تحصيل أو تفعيل باقة مدفوعة حيًا؛ الاشتراك الاصطناعي في الاختبار بقي `pending_payment` دون تسجيل قبض.
4. القوائم المنسدلة للمركبة تستند إلى القيم المعرفة أو المسجلة للشركة؛ لم يُنشأ قاموس مصنع/طراز عالمي أو قاعدة توافق جديدة.

استكمال للوحة الجهات والمستخدمين والأسطول، انطلاقًا من الفرع المنقح الذي كان عند `35a90c29227b06444d368e06da77216d0b7c111d` قبل هذه التغييرات. لا إعادة بناء للأقسام ولا تغيير لتهيئة المالك. لم يُطبّق ترحيل أو كتابة إلى Supabase؛ `0009` ما زال مؤجلًا.

## التحقق المنفذ

- `pnpm --filter @workspace/pertomax-eg-web run typecheck`: ناجح.
- `pnpm --filter @workspace/api-server run typecheck`: ناجح.
- `PORT=25467 BASE_PATH=/ pnpm --filter @workspace/pertomax-eg-web run build`: ناجح.
- `pnpm --filter @workspace/api-server run build`: ناجح؛ حزمة الخادم 3.0 MB وخرائطها 5.0 MB، وهي لا تُحمّل للمتصفح.
- `bash lib/db/rebuild/run-local-test.sh`: ناجح باستخدام PostgreSQL محلي مؤقت وبيانات اصطناعية؛ الاختبارات الحالية تشمل 36 تحققًا لأسطول 0014، و52 تحققًا لدمج الأسطول والمالية، و47 تحققًا لملفات الجهات/المستخدمين وقراءة الاشتراك والحسابات والسعر، إضافة إلى تكاملات المالية والترحيلات. لم يُشغّل `0009`.
- نقاط اختبار API استخدمت خادم HTTP محليًا ونقل Supabase محاكى إلى قاعدة PostgreSQL المعزولة؛ اختبارات سياسة التغطية والحجز استخدمت قاعدة PostgreSQL الحقيقية المؤقتة. هذا ليس اختبارًا حيًا لخدمة Supabase.
- لم تُستخدم جلسة مالك أو تجاوز مصادقة أو إرسال بريد أو تخزين حي. لم تُنشأ بيانات أعمال أو حسابات أو معاملات اختبار في Supabase.

## المراجع والقيود

استُخدمت مكونات وتوكنات المشروع القائمة، وتعليمات React/Vite، ومراجعة تصميم متخصصة على الملفات الحالية. لم أتحقق من فتح مراجع خارجية إذا لم تُحمّل. لم يُطبّق ترحيل، ولم تتغير ACL أو الأسرار أو الاتصالات.

## المتبقي المحدد

1. مراجعة مالك مصرح بها للصفحات بعد تسجيل الدخول على 1280 و1440 وهاتف 390؛ أداة المتصفح المتاحة لا تحمل جلسة المالك.
2. اختبار رفع/تنزيل Storage على Supabase لا يزال مفتوحًا؛ لم أستخدم اتصالًا إداريًا لتجاوزه ولم أرفع ملفًا أو أنشئ سجلًا حيًا.
3. لا تحصيل أو تفعيل باقة مدفوعة حيًا؛ الاشتراك الاصطناعي في الاختبار بقي `pending_payment` دون تسجيل قبض.
4. القوائم المنسدلة للمركبة تستند إلى القيم المعرفة أو المسجلة للشركة؛ لم يُنشأ قاموس مصنع/طراز عالمي أو قاعدة توافق جديدة.
